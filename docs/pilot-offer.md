# Oferta de colaboración para agencias piloto

Estamos desarrollando un prototipo para ayudar a pequeñas inmobiliarias a identificar consultas que necesitan seguimiento y definir el siguiente paso comercial.

Buscamos 2 agencias para revisar su proceso y probar un flujo de priorización con ejemplos sintéticos o información agregada.

## Incluye
- Conversación inicial de 20 minutos.
- Demostración de 5–10 minutos.
- Taller breve para identificar casos que merecen priorización.
- Prueba asistida con datos ficticios, sintéticos o agregados.
- Resumen de aprendizajes y métricas propuestas.

## Pedimos
Una persona responsable, participación de 1–3 agentes, dos sesiones breves de revisión y opinión honesta.

## No incluye
Integración CRM o WhatsApp, importación de contactos reales, envío automático, garantías de más visitas o ventas ni servicio listo para producción.

La colaboración inicial es descubrimiento, no suscripción. Cualquier piloto posterior con datos reales o trabajo operativo necesitará alcance, responsabilidades, seguridad, condiciones y presupuesto acordados por escrito.

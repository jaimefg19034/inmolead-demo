# Lista de comprobación

## Demo pública
- [x] Propuesta clara sin presentarla como producto terminado.
- [x] Datos ficticios identificados.
- [x] Borradores explicados como plantillas locales, no IA.
- [x] Sin promesas de envío o integraciones.
- [x] Alta, edición, búsqueda, filtros, actividad y exportación.
- [x] Indicadores calculados desde registros de ejemplo.
- [x] «Marcar hecho» conserva el contacto.
- [x] Diseño adaptable a móvil.

## Antes de entrevistas
- [ ] Crear una lista de 20 agencias objetivo.
- [ ] Contactar individualmente a 10.
- [ ] Entrevistar sin empezar vendiendo.
- [ ] Registrar CRM, canales, proceso y ejemplos recientes.
- [ ] Comparar necesidades con las funciones del CRM actual.

## Antes de piloto con datos reales
- [ ] Definir responsable/encargado, base jurídica y deber de información.
- [ ] Contratos y acuerdos de tratamiento cuando correspondan.
- [ ] Autenticación, aislamiento por agencia y permisos.
- [ ] Cifrado, secretos, logs y control de accesos.
- [ ] Conservación, eliminación, exportación e incidentes.
- [ ] Evaluar proveedores y transferencias de datos.
- [ ] Revisar políticas de mensajería e IA.
- [ ] Probar seguridad, backups y restauración.

## Antes de cobrar
- [ ] Demostrar uso repetido por agencias.
- [ ] Conseguir compromiso de pago, no solo comentarios.
- [ ] Calcular infraestructura, soporte e integraciones.
- [ ] Definir precio, alcance, contrato y soporte.
- [ ] Revisar obligaciones fiscales y mercantiles con asesoramiento adecuado.

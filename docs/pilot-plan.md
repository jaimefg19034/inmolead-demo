# Diseño de piloto asistido

## Propósito
Comprobar si priorizar seguimientos pendientes mejora la disciplina operativa. No intentar demostrar un aumento de ventas en dos semanas.

## Alcance
- 1–2 agencias independientes, 1 responsable y 1–3 agentes.
- Dos semanas después de entrevista y configuración.
- Una categoría: nuevos leads que necesitan primera respuesta o siguiente acción.

## Antes de empezar
Confirmar problema, flujo y responsable. Usar datos sintéticos o agregados. No usar la demo pública para datos reales: no tiene autenticación, control de acceso ni base de datos segura. Si el piloto implica datos personales, definir antes roles, base jurídica, información, contrato, seguridad, acceso, conservación, borrado e incidentes con asesoramiento cualificado.

## Semana 1
Documentar el proceso actual, medir línea base, seleccionar una categoría de consulta y probar el flujo con datos sintéticos. Registrar alertas útiles y falsas alarmas.

## Semana 2
El agente revisa una lista de tareas y sigue enviando mensajes por su canal habitual. InmoLead no los envía. Registrar tareas completadas, descartadas o reprogramadas. Comparar con la línea base y entrevistar de nuevo.

## Métricas
Tiempo hasta primera respuesta humana, porcentaje de leads con siguiente acción, tareas vencidas resueltas, visitas concertadas tras el seguimiento (sin atribuir causalidad automática), minutos de administración, falsas alarmas y sugerencias descartadas.

## Fuera de alcance
Integraciones, importación de datos reales, envío autónomo, sincronización de calendario y garantías de conversión.

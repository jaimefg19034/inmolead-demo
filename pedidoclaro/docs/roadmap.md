# Roadmap — PedidoClaro

## Fase 0 — Demo y validación
- [x] Prototipo estático con datos ficticios.
- [x] Revisión manual de líneas y cantidades.
- [x] Exportación CSV de demostración.
- [x] Documentar límites y riesgos.
- [ ] 10 entrevistas con un único segmento.
- [ ] Observar el proceso actual y medir tiempos.
- [ ] Conseguir un piloto con alcance y métricas escritos.

## Fase 1 — Piloto controlado
Solo si la validación lo justifica:
- Elegir un formato de entrada y un ERP real.
- Importación de documentos de prueba con datos anonimizados.
- Extracción asistida y catálogo del cliente.
- Confianza por campo y bandeja de excepciones.
- Registro de auditoría y aprobación humana.
- Exportación compatible con el proceso del cliente.

## Fase 2 — Producto
Solo tras un piloto satisfactorio:
- Integración oficial con el ERP elegido.
- Gestión de usuarios y permisos.
- Base de datos y almacenamiento seguros.
- Monitorización, copias de seguridad y soporte.
- Seguridad, privacidad, contratos y evaluación legal.

## No construir todavía
- Integraciones genéricas con diez ERPs.
- Automatización sin aprobación.
- Aplicación móvil nativa.
- Facturación compleja, multi-tenant y pagos.
- IA cara sin ejemplos representativos y métricas.
